## Summary
The drawer draws on a shared canvas with a full set of tools, and every other player sees the drawing appear as it is drawn.

## Stories
- US-005: Drawer draws and guessers see the strokes live
- US-006: Drawer chooses a color and brush size
- US-007: Drawer erases parts of the drawing or clears the canvas
- US-008: Drawer fills an area with a color
- US-009: Drawer undoes the last action

The live list with status is on the dashboard and in the backlog (`npm run sdlc:backlog`).

## Done when
Every tool in R1 (pen, colors, sizes, eraser, fill, undo, clear) works for the drawer and shows up identically for guessers.

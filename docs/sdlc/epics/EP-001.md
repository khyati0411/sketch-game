## Summary
A host opens a private room on their PC and friends on the same Wi-Fi join it from an invite link, wait in a lobby, and the host starts the game.

## Stories
- US-001: Host creates a private room and gets an invite link
- US-002: Player joins a room from the invite link
- US-003: Players see who is in the lobby, live
- US-004: Host starts the game when at least two players are in

The live list with status is on the dashboard and in the backlog (`npm run sdlc:backlog`).

## Done when
A host and at least one other player can get from "start Screwdle" to a running game using only the invite link.

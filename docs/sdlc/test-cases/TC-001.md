## Objective
A host can create a private room in one step and gets a shareable invite link (US-001 AC1, AC2).

## Preconditions
Server running. One browser context on the home page.

## Steps
| # | Step | Expected result |
|---|---|---|
| 1 | Enter nickname "Khyati" and choose "Create room" | The lobby shows; Khyati is listed and marked Host |
| 2 | Look at the invite panel | An invite link ending in `/r/<6-letter code>` and a "Copy link" button are shown |
| 3 | Choose "Copy link" | The clipboard holds the invite link |

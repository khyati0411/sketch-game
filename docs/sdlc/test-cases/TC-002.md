## Objective
The invite link uses the PC's network address and works from another device (US-001 AC3).

## Preconditions
Server started with `npm start` on the owner's PC; a phone or second PC on the same Wi-Fi.

## Steps
| # | Step | Expected result |
|---|---|---|
| 1 | Create a room on the host PC | The invite link uses the "Same network" address the server printed, not `localhost` |
| 2 | Open the link on the second device | The join screen for that room shows |
| 3 | Join as "Maya" | Both devices list Maya in the lobby |

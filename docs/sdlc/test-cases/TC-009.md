## Objective
Drawing is live, not only on pen-up (US-005 AC1, AC2).

## Preconditions
A started game with drawer and two guessers; the drawing turn is in progress.

## Steps
| # | Step | Expected result |
|---|---|---|
| 1 | Drawer presses on the canvas and drags halfway across | The drawer sees a line following the pointer |
| 2 | Before releasing, check a guesser's canvas | The partial line is already visible |
| 3 | Drawer releases | Both guessers show the complete line |

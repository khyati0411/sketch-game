## Objective
The game cannot start with one player, and only the host can start it (US-004 AC2, AC3).

## Preconditions
A room with only the host.

## Steps
| # | Step | Expected result |
|---|---|---|
| 1 | Look at "Start game" | It is disabled with "At least 2 players are needed" |
| 2 | A guest joins and looks at the lobby | The guest sees "Waiting for the host to start" and no start button |

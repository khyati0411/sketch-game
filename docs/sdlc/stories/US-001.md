**As a** host, **I want** to create a private room with one click, **so that** I can invite my friends to a game.

## Acceptance criteria

**AC1: Room is created**
- **Given** I have opened Screwdle on the host PC
- **When** I enter my nickname and choose "Create room"
- **Then** a new private room is created and I am in its lobby as the host

**AC2: Invite link**
- **Given** I am in my new room's lobby
- **When** I look at the lobby
- **Then** I see an invite link with the room code and a "Copy link" button

**AC3: Links work on the network**
- **Given** the server printed a same-network address
- **When** I copy the invite link
- **Then** the link uses that address, so it opens on other devices on the same Wi-Fi

## Notes
Room codes are short and hard to guess (for example 6 letters). Rooms live in server memory (ADR-002).

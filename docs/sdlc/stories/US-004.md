**As a** host, **I want** to start the game when everyone I expect has joined, **so that** we can begin playing together.

## Acceptance criteria

**AC1: Start enabled**
- **Given** I am the host and 2 or more players are in the lobby
- **When** I choose "Start game"
- **Then** the game starts for every player at the same time

**AC2: Start blocked**
- **Given** I am the only player in the lobby
- **When** I look at "Start game"
- **Then** it is disabled and explains that at least 2 players are needed

**AC3: Only the host starts**
- **Given** I am a player but not the host
- **When** I look at the lobby
- **Then** I see "Waiting for the host to start" instead of a start button

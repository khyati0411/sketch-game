**As a** player, **I want** everyone to get a turn to draw in each round, **so that** the game is fair.

## Acceptance criteria

**AC1: Rotation**
- **Given** a game with 4 players has started
- **When** turns complete
- **Then** each player draws exactly once per round, in join order

**AC2: Three rounds**
- **Given** a game has started
- **When** the third round finishes
- **Then** the game ends and no more turns start

**AC3: Round shown**
- **Given** a game is running
- **When** I look at the game header
- **Then** I see "Round x of 3"

## Notes
R1 uses fixed settings: 3 rounds, 80-second turns (design doc §5). Configurable settings come in R2.
